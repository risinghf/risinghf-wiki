# WiserSquare 平台使用说明

WiserSquare是一个智能演示平台，旨在为用户提供更加智能便捷的Lorawan设备演示平台。通过采用Lorawan技术，WiserSquare
能够更加稳定地传输数据，同时具有低功耗和强安全性的特点。在WiserSquare平台上，用户可以轻松展示物联网设备、传感器、定位追踪器等产品的功能和性能，同时还能够实时监控其运行状态，提升演示效果和用户体验。无论是企业展示生产线自动化，还是科技公司展示智能家居产品，WiserSquare都能够为其提供全面的支持和帮助。

本手册介绍 WiserSquare 平台的账号登录、固件版本管理，以及设备端通过 HTTP 协议接入平台的上行与下行接口。GN1S067 相关设备请参考：[《WiserSquare-GN1S067使用手册》](./02.GN1S067使用手册.md)。

## 3 设备上行 HTTP 协议接入

已注册了产品类型的设备可以直接通过 HTTP 协议接入 WiserSquare 平台：设备主动 `POST` 上报上行数据，
并通过 `GET` 接口定期拉取平台下发的下行数据。该方式实现简单、无需维持长连接，适用于低频上报或资源受限的设备。


### 3.1 通用请求头

所有接口的 HTTP 请求头均需携带以下字段：

| 字段名字           | 类型     | 描述                                                     |
|:---------------|:-------|:-------------------------------------------------------|
| x-access-token | string | 使用 x-id / x-version 和预置密钥通过 MD5 / Base64 算法生成的签名       |
| x-id           | string | 设备唯一 ID                                                |
| x-version      | string | 软件版本号                                                  |
| x-product      | string | 产品型号，比如 `GN1S067`                                       |

Token生成算法为 `Base64(MD5("<产品密钥>,<设备ID>,<软件版本号>"))`，即将密钥、设备 ID、软件版本号以英文逗号拼接后做 MD5 摘要，再对摘要字节做 Base64 编码。

Golang 生成 `x-access-token` 的示例代码如下：

```go
func generateAccessToken(id string, version string, secret string) string {
    digestStr := fmt.Sprintf("%s,%s,%s", secret, id, version)
    h := md5.New()
    _, _ = io.WriteString(h, digestStr)
    digestByte := h.Sum(nil)
    return base64.StdEncoding.EncodeToString(digestByte)
}
```

Python 生成 `x-access-token` 的示例代码如下：

```python
import hashlib
import base64

secret = 'eNQmGcPsU45MrF1v'


def generateAccessToken(id, version):
    md5_obj = hashlib.md5()
    md5_data = f"{secret},{id},{version}".encode("ASCII")
    md5_obj.update(md5_data)
    return base64.b64encode(md5_obj.digest()).decode('ascii')


if __name__ == "__main__":
    assert "wVg7zStI+yAd9OMz/32wJw==" == generateAccessToken("abcdefg", "1.1")
    assert "HCZOMPgolTRJq6ObsLmOQA==" == generateAccessToken("abcdefg", "1.2")
```

### 3.2 发送上行

`POST https://wisersquare.risinghf.com/api/uplink/push`

Body 格式：JSON

请求字段：

| 字段名字 | 类型     | 是否必选 | 描述                                                         |
|:-----|:-------|:-----|:-----------------------------------------------------------|
| data | string | 是    | 二进制数据包字节通过 base64 算法转换，例如字节 `[0x31 0x31 0x31]` base64 转换后为 `MTEx` |

请求示例：

```json
{
  "data": "MTEx"
}
```

响应字段解释：

| 字段名字 | 类型   | 描述                              |
|:-----|:-----|:--------------------------------|
| code | uint | 0 表示成功，非 0 表示失败，此时 msg 会显示错误原因 |

响应示例：

```json
{
  "code": 0,
  "msg": ""
}
```

### 3.3 获取待发送的下行

`GET https://wisersquare.risinghf.com/api/downlink/pull`

非实时的用法，适用于低频的下行，由设备定期拉取。

响应字段解释：

| 字段名字        | 类型     | 描述                     |
|:------------|:-------|:-----------------------|
| msgId       | uint   | 下行唯一 id                |
| data        | string | 二进制数据包字节通过 base64 算法转换 |
| morePackets | uint   | 下行队列中是否还有更多数据包         |
| code        | uint   | 错误码，为 0 是执行成功，非 0 则是错误 |

错误码定义：

| 错误码 | 描述                       |
|:----|:-------------------------|
| 0   | 执行成功                     |
| 404 | 没有下行，此时 data 结构中无数据      |
| 其它  | msg 带有错误信息，可打印到终端以便诊断问题 |

响应示例：

```json
{
  "code": 0,
  "msg": "",
  "data": {
    "data": "MTEx",
    "msgId": 8,
    "morePackets": 0
  }
}
```
