## 2. 服务管理

### 2.1 使用 start_all.sh（推荐）

`start_all.sh` 是 4.2.6 版本内置的一体化运维脚本，支持启动/停止/检查/重启/日志等功能。

```bash
# 启动所有服务（默认拉取最新镜像）
./start_all.sh

# 启动但不拉取镜像（使用本地镜像）
./start_all.sh --no-pull

# 停止所有服务
./start_all.sh -s

# 查看运行中的容器
./start_all.sh -l

# 检查环境（Docker/磁盘/内存/CPU/容器状态）
./start_all.sh -c

# 拉取最新镜像
./start_all.sh -p

# 重启指定容器
./start_all.sh -r iotsquare
./start_all.sh -r emqx1

# 跟踪日志（全部服务）
./start_all.sh -f

# 跟踪日志（指定服务）
./start_all.sh -f iotsquare
./start_all.sh -f iotsquare-core

# 显示帮助
./start_all.sh -h
```

### 2.2 使用 Docker Compose 原生命令

```bash
cd ~/iotsquare-docker/

# 启动所有服务
docker compose up -d

# 停止所有服务
docker compose down --remove-orphans

# 查看服务状态
docker compose ps

# 重启单个服务
docker compose restart iotsquare

# 重建单个容器（配置变更后）
docker compose up -d --force-recreate --no-deps iotsquare
```

### 2.3 启动可选服务

`iotsquare-mqtt-openapi-adapter` 默认不启动（配置了 `profiles: iotsquare-mqtt-openapi-adapter`），如需启动：

如果需要基于MQTT的openAPI，则需要启动：
```bash
docker compose --profile iotsquare-mqtt-openapi-adapter up -d
```

## 4. 数据库运维

### 4.1 连接数据库

```bash
# 通过Docker本地端口连接
docker exec -it postgresql13 psql -U iotsquare -d iotsquare
```

### 4.2 日常巡检SQL

```sql
-- 查看数据库大小
SELECT pg_size_pretty(pg_database_size('iotsquare'));

-- 查看最大的10张表
SELECT schemaname, tablename,
       pg_size_pretty(pg_total_relation_size(schemaname||'.'||tablename)) as total_size
FROM pg_tables
WHERE schemaname NOT IN ('pg_catalog', 'information_schema')
ORDER BY pg_total_relation_size(schemaname||'.'||tablename) DESC
LIMIT 10;

-- 查看当前连接数
SELECT count(*) FROM pg_stat_activity;

-- 查看连接状态分布
SELECT state, count(*) FROM pg_stat_activity GROUP BY state ORDER BY count DESC;

-- 查看长时间空闲连接
SELECT pid, usename, state, now() - state_change as idle_time
FROM pg_stat_activity
WHERE state = 'idle' AND now() - state_change > interval '10 minutes'
ORDER BY idle_time DESC;


-- 查看慢查询(执行时间>3秒)
SELECT query, now() - query_start as duration
FROM pg_stat_activity
WHERE state = 'active' AND now() - query_start > interval '3 seconds';

-- 查看缓存命中率
SELECT sum(blks_hit)*100.0/(sum(blks_hit)+sum(blks_read)) as cache_hit_ratio
FROM pg_stat_database;
```

### 4.3 PostgreSQL连接数超限

**现象**: `sorry, too many clients already` 或 `FATAL: remaining connection slots are reserved`

**排查**:
```bash
# 查看当前连接数
docker exec postgresql13 psql -U postgres -c "SELECT count(*) FROM pg_stat_activity;"

# 数据库重启
docker compose restart postgresql13

```

#### 3.4.4 Docker日志清理

Docker容器日志已配置容器日志限制，但长期运行仍可能积累：

```bash
# 查看磁盘占用
sudo df -h
sudo du -h --max-depth=1 /var/lib/docker/
# 清理所有容器日志(立即释放空间)
sudo sh -c 'truncate -s 0 /var/lib/docker/containers/*/*.log'

# 清理未使用的Docker资源
docker system prune -a --volumes

# 重建容器(最快方式)
sudo docker rm -f iotsquare-core
sudo docker rm -f iotsquare
cd ~/iotsquare-docker/
sudo docker compose up -d

```

#### 3.4.5 EMQX因磁盘满崩溃

**现象**: EMQX崩溃，日志显示 `enospc` (No space left on device)

**解决**:
```bash
# 1. 释放磁盘空间(参考3.4.3节)
# 2. 清理EMQX日志
docker exec -it emqx1 sh -c 'cd /opt/emqx/log && rm -f *.gz && truncate -s 0 erlang.log.*'
# 3. 重启EMQX
docker compose restart emqx1
```
