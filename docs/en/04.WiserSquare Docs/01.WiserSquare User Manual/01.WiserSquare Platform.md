# WiserSquare Platform Manual

WiserSquare is an intelligent demonstration platform developed on LoRaWAN technology, designed to provide users with a smarter and more convenient demonstration platform. By adopting LoRaWAN technology, WiserSquare can transmit data more stably, and features low power consumption and strong security. On the WiserSquare platform, users can easily demonstrate the functions and performance of IoT devices, sensors, trackers and other products, and monitor their running status in real time to improve the demonstration effect and user experience. Whether an enterprise is demonstrating production line automation or a technology company is demonstrating smart home products, WiserSquare can provide comprehensive support and assistance.

This manual covers account login and firmware version management on the WiserSquare platform. For GN1S067 devices, see [WiserSquare-GN1S067 User Manual](./02.GN1S067%20User%20Manual.md).

## 1. Login
At present, when users use the WiserSquare platform for the first time, they need to apply for an account from the RisingHF platform administrator. After obtaining the account, visit [WiserSquare](https://wisersquare.risinghf.com/) and you will be redirected to the login page.

---

![login](https://risinghf-wiki.oss-cn-shenzhen.aliyuncs.com/upload/img/20230620183513.png)

---

Use the assigned account and password to log in to the `WiserSquare` platform.

---

![home](https://risinghf-wiki.oss-cn-shenzhen.aliyuncs.com/upload/img/20230620183737.png)

---

By default you are redirected to the main page of the platform. The sidebar of the main page has function buttons for user management, device list and firmware version list; the top right corner has function buttons for Chinese/English switching and user details;
the main page shows statistics for the number of devices under the current user, the number of devices currently in alarm and the current alarm device list; click the current device list to open the device details and query the device's alarm history;
