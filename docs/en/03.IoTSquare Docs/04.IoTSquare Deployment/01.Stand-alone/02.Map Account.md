### 1. Apply for an AMap API Key

#### 1. Open the official website

https://lbs.amap.com/

![1785223724614](http://risinghf-wiki.oss-cn-shenzhen.aliyuncs.com/upload/genlusys/map/1785223724614.png)

#### 2. Sign in

Choose to sign in with your account or mobile phone number.

![1785223525315](http://risinghf-wiki.oss-cn-shenzhen.aliyuncs.com/upload/genlusys/map/1785223525315.png)

#### 3. Developer verification

After signing in, click **Console** to open the AMap console. We choose **Individual Developer**. If you cannot find the entry, you can use the link below:

https://console.amap.com/dev/id/perfect?type=person-alipay

After completing the required verification steps, your individual developer verification will be finished.

![1785223887726](http://risinghf-wiki.oss-cn-shenzhen.aliyuncs.com/upload/genlusys/map/1785223887726.png)

#### 4. Create an application

Click **Create Application** in the upper-right corner. Enter the application name and select the application type, then complete the application creation.

![1785224025191](http://risinghf-wiki.oss-cn-shenzhen.aliyuncs.com/upload/genlusys/map/1785224025191.png)

#### 5. Add a key

Enter the Key name, select **Web Service** for the service platform, check **I have read and agree to...**, then click the **Submit** button.

![1785224127759](http://risinghf-wiki.oss-cn-shenzhen.aliyuncs.com/upload/genlusys/map/1785224127759.png)

#### 6. Key creation completed

At this point, the Key has been created. This is our API Key. It is very important, so please keep it safe and do not disclose it.

![1785224200904](http://risinghf-wiki.oss-cn-shenzhen.aliyuncs.com/upload/genlusys/map/1785224200904.png)



### 2. Apply for a Google Maps API Key

#### 1. Sign in

Click the link below to sign in with your Google account and create a project.

https://cloud.google.com/console/google/maps-apis/overview

#### 2. Create a project

Click the project drop-down menu, then select or create the project you want to add the API key to.

![1785227871484](http://risinghf-wiki.oss-cn-shenzhen.aliyuncs.com/upload/genlusys/map/1785227871484.png)

#### 3. Create credentials

Click the **Menu** button, then select **APIs & Services** > **Credentials**.

![1785228021019](http://risinghf-wiki.oss-cn-shenzhen.aliyuncs.com/upload/genlusys/map/1785228021019.png)

On the **Credentials** page, click **Create credentials** > **API key**.

![1785228197242](http://risinghf-wiki.oss-cn-shenzhen.aliyuncs.com/upload/genlusys/map/1785228197242.png)

The **API key created** dialog will display the new API key you just created.

![1785228312456](http://risinghf-wiki.oss-cn-shenzhen.aliyuncs.com/upload/genlusys/map/1785228312456.png)

#### 4. Restrict the API key (optional)

It is strongly recommended that you restrict your API key. Restrictions provide better security and help ensure that only authorized requests use your API key.

![1785228951214](http://risinghf-wiki.oss-cn-shenzhen.aliyuncs.com/upload/genlusys/map/1785228951214.png)

#### 5. Link a billing account (optional)

If you need usage beyond the free quota, you will need to upgrade to a paid plan.

![1785229069186](http://risinghf-wiki.oss-cn-shenzhen.aliyuncs.com/upload/genlusys/map/1785229069186.png)

![1785229085534](http://risinghf-wiki.oss-cn-shenzhen.aliyuncs.com/upload/genlusys/map/1785229085534.png)
